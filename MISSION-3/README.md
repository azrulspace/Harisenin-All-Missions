# Mission 3: E-Learn Premium Online Courses

Ini adalah proyek untuk Mission 3 dari bootcamp Harisenin. Proyek ini difokuskan pada pembuatan *Landing Page* statis untuk sebuah platform pembelajaran online bernama **E-Learn** menggunakan murni **HTML dan CSS** (Vanilla).

## Fitur dan Struktur Halaman

Proyek ini mendemonstrasikan implementasi antarmuka pengguna (UI) modern dengan fokus pada tipografi yang jelas, warna yang menarik, dan responsivitas. Berikut adalah bagian-bagian utama dari *landing page* ini:

1. **Navigation Bar (Navbar):**
   - Menampilkan logo dan *brand name*.
   - Menyediakan tautan menu navigasi utama (Courses, Mentors, Pricing, Resources).
   - Memiliki tombol aksi (Log in, Sign up).
   - Sudah dilengkapi dengan menu *hamburger* (Mobile Menu) interaktif menggunakan sedikit sentuhan JavaScript.

2. **Hero Section:**
   - Bagian *header* dengan teks *headline* menggunakan *gradient text*.
   - *Call-to-Action* (CTA) "Start learning now".
   - Dilengkapi *badge* informasi rilis kursus baru dan gambar ilustrasi yang relevan.

3. **Courses Section (Kelas Unggulan):**
   - Grid layout yang menampilkan kartu (*card*) dari kelas-kelas unggulan (seperti Git & GitHub, UX Research, Python, C++).
   - Setiap kartu kursus memiliki ikon, informasi jumlah materi, *badge* level (Pemula/Menengah), jumlah ulasan, ketersediaan sertifikat, harga, dan tombol "Beli".

4. **Features Section (Keunggulan E-Learn):**
   - Menggunakan Grid layout untuk menampilkan nilai jual platform, seperti: *Expert-led Courses*, *Interactive Projects*, dan *Career Growth*.
   - Dilengkapi dengan ikon vektor bergaya minimalis.

5. **Footer:**
   - Bagian penutup sederhana yang memuat *copyright* dan logo E-Learn.

## Teknologi Utama
- **HTML5:** Struktur semantik, penggunaan SVG inline untuk ikon.
- **CSS3:** Custom Variables (CSS Root), Flexbox, CSS Grid, efek *hover*, *transitions*, *shadow*, dan *gradients*.
- **JavaScript (Vanilla):** Sederhana dan ringan untuk fungsionalitas menu navigasi *mobile* (*toggle class*).

## Cara Menjalankan Proyek
Anda tidak perlu instalasi khusus (*no build step*). Cukup jalankan dengan membuka file `index.html` di web browser modern mana pun (Google Chrome, Firefox, Safari, dll).
